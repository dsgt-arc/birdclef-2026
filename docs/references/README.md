# References

Reference notes capture external knowledge used during BirdCLEF+ 2026. They are provenance and background, not all current recommendations.

## Status categories

| Category | Meaning |
|---|---|
| Canonical reference | Still useful for the working note or final project conclusions. |
| Historical reference | Useful for provenance or early decisions, but superseded by experiment results. |
| Deep-research synthesis | AI-generated or heavily synthesized background; use as a lead generator, not a source of truth. |
| Kaggle capture | Clean-room summaries of notebooks/discussions; cite the original Kaggle source when possible. |

## Cleanup rule

Prefer adding a status note or moving an item under a clearly labeled subdirectory over deleting. Delete only if a note is duplicated elsewhere and has no unique provenance, link, or quote worth preserving.
