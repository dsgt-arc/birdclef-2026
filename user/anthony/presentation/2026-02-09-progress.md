## Exp 005 — Scaling Regimes

1. **Floor** (<3k tokens): fixed ~28ms overhead dominates
2. **Linear** (6k–24k): SSM compute dominates, peak 142k tok/s
3. **Superlinear** (>48k): activations exceed GPU L2 cache

## Exp 005 — Practical Implications

- **Best configs for BirdCLEF**:
  - framelevel-128×1 (3k tokens, 29ms) — full frequency, 10ms resolution
  - quarterframe-32×1 (12k tokens, 84ms) — peak throughput, 4 freq bands
- **Memory for training**: 3k tokens → ~90 samples/batch on 24GB; 12k → ~33/batch
- **Conclusion**: speed and memory are solved — learning quality is the bottleneck

## Exp 006 — Diagnosing the Gap

- The **0.086 vs 0.48 gap** is too large for a single factor
- **Ranked causes**:
  1. **No pre-training** (dominant) — ConvNeXT uses ImageNet features
  2. **Zero negatives in training** — all chunks labeled positive, but validation is ~55% empty
  3. **Architecture suitability** — from-scratch ViT still gets 0.164
  4. **Training dynamics** — lr, augmentation, batch size need tuning
- **Key insight**: forward pass is 29ms — speed is fine; **learning quality** is the bottleneck

## Concept — Unsupervised Event Detection

- **Problem**: all training chunks labeled positive (no negatives)
- **Solution**: bambird detects vocalization events in XenoCanto recordings
  - Chunks **without** detected events become natural negatives
  - Lightweight, proven approach (BirdSet uses it internally)
  - One-time preprocessing cost, cached with spectrograms
- **Impact**: directly addresses the zero-negatives problem from exp 006

## Concept — Weak Supervision Label Fusion

- **Combine multiple noisy sources**: bambird, ConvNeXT, BirdNET, energy detector
- **FlyingSquid triplet method**:
  - Closed-form accuracy estimation — no ground truth needed
  - Produces calibrated soft labels with per-source accuracy weights
  - ~30 lines numpy, instant computation, no hyperparameters
- **Result**: better labels than any single source alone

## Concept — Learned Frequency Tokenizer

- **Problem**: Linear(128, 192) is too weak — no nonlinearity, no hierarchy
- **Solution**: LEAF (learnable Gabor filterbank) + frequency attention + Mamba
  - LEAF: 30K params, learns filterbank from data
  - Frequency attention: 1–2 transformer layers over 128 freq tokens
- **Quick diagnostic first**: swap Linear for 3-layer MLP to test if depth matters
- **Modular SSL**: pre-train frequency encoder and Mamba backbone separately

## Concept — Pre-trained Mamba Transfer

:::::::::::::: {.columns}
::: {.column width="50%"}

- Load AudioSet pre-trained SSAMBA weights
- Re-initialize **only** patch embedding (~1% of params)
- Mamba layers transfer naturally — state dynamics are about audio, not tokenization

:::
::: {.column width="50%"}

**Length extension — Mamba vs Transformer:**

| Property | Mamba | Transformer |
|:---------|:-----:|:-----------:|
| Pos. encoding | None | Required |
| Train 10s → eval 60s | Native | Degrades |
| Memory scaling | O(1) | O(n²) |
| Speed scaling | O(n) | O(n²) |

:::
::::::::::::::

## Concept — Prompted Sound Event Detection

- **Reference audio clip as Mamba prefix** → per-token binary output
- Solves: domain gap, low-resource species, zero-shot detection
- Mamba as **learned matched filter**: O(n+m) vs O(n·m) cross-attention
- **3-stage training**:
  1. SSL pre-training (masked token prediction)
  2. Episode-based prompted SED (within-recording, cross-recording, negatives)
  3. Soundscape adaptation with pseudo-labels
