## Concept Docs

**Token Architecture**

- Discrete audio tokens (WavTokenizer: 40–75 tokens/sec) instead of spectrogram patches
- 60s audio = ~4,500 tokens — tractable for Mamba, expensive for attention
- Bidirectional Mamba for full-sequence context
- Multi-task: classification + SED + reconstruction heads

**Pretraining Compute Feasibility**

- PACE budget: ~200–500 GPU-hours
- Strategy ladder: distillation (10–50h) → patch surgery (5–20h) → small SSL (50–200h)
