- Site-blend regularization is now the cleanest live path: anchoring `site_blend_logit` back toward the 18% prior made the otherwise-too-fast `site_blend_lr_mult=5` setting almost tie the 4.5× best (`0.771745` vs `0.771837`). Refine the anchor strength downward (roughly `2e-4`–`8e-4`) and, if that stalls, try the same anchor on the 4.5× baseline instead of abandoning selective regularization.
- Focal-subset construction remains highly quantized and load-bearing: `FOCAL_CACHE_SIZE=17408` is dramatically better than nearby sizes, and a high-coverage `FOCAL_CACHE_SEED=104` draw regressed badly. If revisiting subset search, do it empirically on the proxy or with a more targeted objective tied to bird/with_focal balance; naive species/family-coverage heuristics are stale.
- Local geometry sweeps are mostly bracketed already (`4` heads > `2`/`8`, `K_species=8` > `6`/`12`, `K_site=8` > `4`). Next architecture moves should change *how* site conditioning is applied—e.g. norm/gating on the attention update, learned residual scaling, or asymmetric species-vs-site projection structure—rather than adding raw capacity.
- The Perch-logit side branch is still deferred but not dead: the current 14,795-d path is operationally wrong because cache → DataLoader → GPU transport times out. Revisit only after compressing logits at cache-build time (e.g. BirdCLEF-species-mapped logits or another compact summary) so the extra signal is cheap enough for the fast proxy.
