# Experiment 001: Reproducibility Guide

## Overview

This experiment evaluated BirdNET and Perch models on BirdSet HSN dataset using:
- **Phase 2A**: Direct inference with pre-trained models
- **Phase 2B**: Transfer learning with linear probes

## Environment Snapshot

**Created**: 2026-01-31
**Python**: 3.11
**Key Dependencies**: PyTorch 2.10.0, TensorFlow 2.17.0, BirdSet Bioacoustics Model Zoo

## Files

| File | Purpose |
|------|---------|
| `requirements-exp001.txt` | Direct dependencies used in this experiment |
| `requirements-frozen.txt` | Full pip freeze (all packages, including transitive deps) |
| `freeze_environment.sh` | Script to regenerate frozen requirements |

## Reproducing This Experiment

### Quick Start (Direct Dependencies)

```bash
# Create virtual environment
uv venv .venv --python 3.11
source .venv/bin/activate

# Install dependencies
uv pip install -r requirements-exp001.txt

# Install bioacoustics-model-zoo (not on PyPI)
uv pip install git+https://github.com/kitzeslab/bioacoustics-model-zoo.git@main

# Install local package
cd ../..  # Go to user/murilo/
uv pip install -e .
```

### Exact Reproduction (Frozen Dependencies)

For exact reproduction including all transitive dependencies:

```bash
uv venv .venv --python 3.11
source .venv/bin/activate
uv pip install -r requirements-frozen.txt
cd ../..
uv pip install -e .
```

**Note**: `requirements-frozen.txt` should be generated by running `freeze_environment.sh` in the original environment.
