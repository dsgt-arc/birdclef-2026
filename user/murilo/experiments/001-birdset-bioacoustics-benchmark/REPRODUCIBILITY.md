# Experiment 001: Reproducibility Guide

## Overview

This experiment evaluated **BirdSet-native models** (ConvNeXT and EfficientNetB1) on all 8 BirdSet evaluation datasets using direct inference.

**What was completed (Phase 2A)**:
- 16 inference runs (2 models × 8 datasets)
- Total samples: 321,819 per model (643,638 total)
- Metrics: cmAP, AUROC, T1-Acc, F1 scores, throughput
- Validation against BirdSet paper baselines

**What was NOT completed**:
- ❌ Phase 2B: BirdNET/Perch evaluation (deferred as future work)
- ❌ Phase 3: Cross-model visualizations
- ❌ Phase 4: Final documentation and artifact archival

See `RESULTS_SUMMARY.md` for complete results and analysis.

## Reproducing This Experiment

### Quick Start (Direct Dependencies)

```bash
# Create virtual environment
uv venv .venv --python 3.11
source .venv/bin/activate

# Install dependencies
uv pip install -r requirements-exp001.txt

# Install local package
cd ../..  # Go to user/murilo/
uv pip install -e .
```

### Exact Reproduction (Frozen Dependencies)

For exact reproduction including all transitive dependencies:

```bash
uv venv .venv --python 3.11
source .venv/bin/activate
uv pip install -r requirements-frozen.txt
cd ../..
uv pip install -e .
```

**Note**: `requirements-frozen.txt` should be generated by running `freeze_environment.sh` in the original environment.

## Running the Experiment

### Phase 2A: BirdSet-Native Models (Completed)

```bash
# Run inference for both models on all 8 datasets
pytest tests/001-birdset-bioacoustics-benchmark/ -v -k "phase_2a"

# Or run specific models/datasets
pytest tests/001-birdset-bioacoustics-benchmark/ -v -k "convnext"
pytest tests/001-birdset-bioacoustics-benchmark/ -v -k "efficientnet"
```

**Models Evaluated**:
- BirdSetConvNeXT (from BirdSet benchmarks)
- BirdSetEfficientNetB1 (from BirdSet benchmarks)

**Datasets** (all 8 BirdSet evaluation datasets):
- POW, PER, NES, UHH, HSN, NBP, SSW, SNE

### Phase 2B: External Models (NOT Completed - Future Work)

Phase 2B (BirdNET and Perch evaluation) was **not completed** in this experiment. It was deferred as valuable future work.

**What Phase 2B would have included**:
- Embedding extraction from BirdNET (1024-dim) and Perch (1280-dim)
- Training multi-label linear probes on extracted embeddings
- Comparing transfer learning vs. direct inference

**Why deferred**: Phase 2A successfully validated the experimental pipeline and BirdSet checkpoints. Phase 2B represents significant additional work that is valuable but not required for experiment closure.

## Results Summary

**Primary Metric (cmAP) - Mean across 8 datasets**:
- BirdSetConvNeXT: **0.36** (matches BirdSet paper: 0.36)
- BirdSetEfficientNetB1: **0.35** (matches BirdSet paper: 0.35)

**Best Performing Datasets**:
1. NBP: 0.62-0.63 cmAP (51 species, 342 samples)
2. POW: 0.34-0.35 cmAP (48 species, 4,560 samples)
3. SSW: 0.34-0.37 cmAP (81 species, 205,200 samples)

**Most Challenging Datasets**:
1. PER: 0.17-0.18 cmAP (132 species, Amazon diversity)
2. UHH: 0.22-0.25 cmAP (27 species, Hawaiian endemics)
3. SNE: 0.30-0.34 cmAP (56 species, European context)

**Validation Status**:
- ✅ cmAP: Excellent alignment with BirdSet paper (mean difference 0.00)
- ✅ AUROC: Very good alignment (mean difference ≤0.01)
- ⚠️ T1-Acc: Systematic difference (different methodology, doesn't affect primary metric)

See `RESULTS_SUMMARY.md` for complete analysis and per-dataset breakdowns.
